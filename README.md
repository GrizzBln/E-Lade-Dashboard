# Ladelog

Ladeprotokoll für den BYD Dolphin Surf mit Kostenvergleich zum Seat Ibiza.

- Eine Seite: `index.html`. Kein Server nötig, läuft auf GitHub Pages.
- Ladungen trägst du direkt auf der Webseite ein. Es gibt keine zweite Datei zum Pflegen.
- Die Einträge liegen im Browser (localStorage) und nicht auf GitHub. Sichere sie ab und zu über „Daten sichern“.
- Optional: eigene Fotos der Autos im Ordner `bilder` (siehe dort).
