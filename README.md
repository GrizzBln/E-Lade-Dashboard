# Ladelog

Ladeprotokoll für den BYD Dolphin Surf mit Kostenvergleich zum Seat Ibiza.

- Eine Seite: `index.html`. Kein Server nötig, läuft auf GitHub Pages.
- Ladungen trägst du direkt auf der Webseite ein (Kilometerstand ist Pflicht). Der Verbrauch wird aus den Kilometerständen berechnet.
- Die Einträge liegen im Browser (localStorage). Optional gleicht die Seite sie automatisch mit einem privaten GitHub-Repository ab (ganz unten unter „Weitere Optionen“).
- Manuelle Sicherung als Datei ebenfalls unter „Weitere Optionen“.
- Optional: eigene Fotos der Autos im Ordner `bilder` (siehe dort).
